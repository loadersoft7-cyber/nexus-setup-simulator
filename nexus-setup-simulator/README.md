# Nexus Setup — визуальный симулятор установщика

Мастер установки в формате 4 шагов (Welcome → Options → Install → Done).  
**Ничего не скачивает и ничего не ставит на диск.** Это только интерфейс.

Каждый запуск заново бросает:

- размер пакета (примерно 168–886 MB)
- номер сборки (`vX.Y.Z-stable / beta / lts / rc1`)
- путь по умолчанию
- скорость, ETA и лог на шаге Install
- итоговое время установки на экране Done (18–97 секунд)

## Быстрый просмотр без сборки

Открой `src/index.html` в браузере. Так можно сразу проверить внешний вид.

## Сборка EXE на GitHub

1. Создай новый репозиторий и залей эту папку.
2. GitHub → **Actions** → workflow **Build Windows EXE** → **Run workflow**.
3. После сборки скачай артефакт `NexusSetup-windows` — внутри portable `.exe`.

Локально (нужны Node.js 20+ и Windows или wine):

```bash
npm install
npm start          # окно установщика
npm run dist       # portable exe в папке dist/
```

## Что менять под себя

| Файл | Что внутри |
|---|---|
| `src/index.html` | тексты, название, издатель |
| `src/styles.css` | цвета, шрифты, карточки |
| `src/app.js` | диапазоны рандома, фазы лога, длительность анимации |

Бренд по умолчанию: **Nexus** / **Halcyon Works**. Палитра — тёмный уголь + античное золото + мятный акцент на завершённых шагах. Формат шагов тот же, что на референсе, оформление другое.
